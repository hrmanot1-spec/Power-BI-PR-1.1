A two-page sales analysis report following the Red & White Skill Education Power BI Practical Report 1 rubric (Tasks 1–13).

The included `data/Sample - Superstore_Practice.csv` is **synthetic practice data** with 9,994 rows and the 21-column Sample Superstore schema. It is not the original Kaggle download. The assignment specifies Kaggle dataset `vivek468/superstore-dataset-final`.
